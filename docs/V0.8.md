# v0.8：完整基础动作与主角体型

> 攻击移动规则已由 [v0.8.1](V0.8.1.md) 更新：所有攻击全程原地停步，冲刺接 J/K 也不再前冲。

本轮先完成主角基础动作。道中神将希耶提与最终巴布的方向保留，尚未加入 Boss 战。

## 素材与体型

保留原有 idle/walk/punch 三张透明图，新增 combat-atlas 与 reactions-atlas 两张透明图，共 48 个源姿势，组成 22 组可预览动作。两张新增图由内置 imagegen 参考现有普通拳图制作，部分动作共享关键姿势，并非每组都有独立原画。

每张源图按统一比例打包成 256×256 的运行时精灵帧，脚底固定 y=244，倒地不会被放大至站立身高。主角 `PLAYER_SCALE = 0.56`，站立约 116px；普通敌人原图 76px，主角约高 1.5 倍。角色原点与碰撞体共用此缩放，使脚底与同一战斗行的普通敌人齐平。Boss 后续建议身高约 155～180px，再按具体造型调整。

### 衔接规则

- 攻击朝向在出招时锁定，前摇、有效帧和收招均不能自由移动。v0.8 原有冲刺攻击位移已在 v0.8.1 移除。
- 攻击帧和伤害使用同一时间线。按键当刻无伤害，前摇受击会取消尚未打出的攻击。有效时间内可碰到新的敌人，同一招对同一目标（包括格挡目标）仅结算一次。
- J 前两段的最后 140ms 可以预输入下一次 J/K。只缓存一次，不叠加整套连招；硬直、倒地、起身、暴怒发动、死亡和重开均清空缓存。
- 抓取在伸手帧寻找目标；痛殴在拳头伸展帧扣血；投掷在放手帧恢复敌人物理运动。投掷前受击只松手，不留下延迟飞出的敌人。
- 空格可取消当前招式发动暴怒；持有敌人时先松开并推离。发动即免伤，480ms 发动后保留完整 10 秒暴怒时间。
- 胜利和死亡暂停物理，但继续播放对应动作；按 R 完整重置。

## 动作预览

运行 `npm run dev`，在本地地址后加 `/animations.html`。页面提供 22 组动作卡片、暂停、重播、0.5 倍慢放、左右镜像。金色提示显示动作判定时间；地面线用于检查脚底落点。`npm run build` 会同时构建游戏与预览页。

## 调整入口

- `src/main.js`：`PLAYER_SCALE` 控制主角显示尺寸，紧随创建精灵的 `setOrigin` 保持脚底位置；攻击范围以场景距离计算。
- `src/player-actions.js`：姿势顺序、每帧时间、命中时机、有效时间与伤害。
- `src/player-art.js`：源图分区和脚底打包。冲撞、投掷所在行有独立列边界，防止相邻角色尾巴串帧。
- `public/characters/bii/`：全部主角原始素材；生成记录见 `docs/ART-PROMPTS.md`。

## 验证

45 项自动化逻辑检查覆盖出拳帧才命中、同招只伤一次、收招输入缓存、朝向锁定、抓取/痛殴/投掷时机、冲刺位移、受击打断、长帧处理、死亡和重开，以及原有敌人、盾牌和波次行为。已完成生产构建与 48 帧实际打包检查，并逐帧检查透明边缘和脚底落点。

当前环境没有可用浏览器程序，下载亦超时，因此未完成真实浏览器中的 Phaser 动画及战斗手感试玩。建议本地重点试：J-J-J / J-J-K；冲刺接 J/K；抓住后 J/K/L；受击时攻击是否立即取消；连续死亡重开；最后进入预览页检查镜像与慢放。
