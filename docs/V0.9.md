# v0.9：神将希耶提试炼

六波杂兵之后新增第四个战斗区，保留攻击全程原地停步的规则。这是参考 Relink 读招、Overdrive／Break 节奏制作的同人机制原型，招式命名与数值均为本项目设计，尚未接入正式 Boss 美术。

## 进入与重试

- 运行 `npm run dev`，在页面下方点击「神将希耶提挑战」，或打开 `/?boss=siete`。
- 完整关卡保留原有三个杂兵区域，清完后向右进入神将试炼。甲板长度由 3600px 扩展至 4560px。
- Boss 区域入口恢复全部生命；失败后 R 满血重试 Boss，怒气重新从零开始。页面下方「完整关卡」从头开始。
- Boss 出场前计入待生成敌人，不能在出场延迟内提前通关；击败后经过波次结算完成第一段。

## 战斗参数

| 项目 | 当前值 |
| --- | --- |
| Boss 生命 / 追击速度 | 90 / 65px 每秒 |
| 横扫 | 前方 190×96px；800ms 预警；1100ms 收招；命中扣 2 点生命并击倒 |
| 落剑 | 三个半径 48px 的固定圆形区域；1100ms 预警；1250ms 收招；命中扣 1 点生命 |
| 交叉剑阵 | 横向 76px 宽带与纵向 106px 宽带；1300ms 预警；1500ms 收招；命中扣 2 点生命并击倒 |
| 超限 Overdrive | 生命降至 60%；预警缩短 150ms、收招缩短 200ms；加入交叉剑阵 |
| 超限量表削减 | J 第一／二／三击：6／7／12；K：18；J-J-K：26；冲刺 J／K：14／30；投掷碰撞：20 |
| Break | 量表清空时触发；4.2 秒不移动、不出招；承伤 ×1.5，向上取整 |
| Break 结束 | 恢复常态；至少 9 秒后才能再次进入超限 |

预警开始时锁定方向和区域，移动不会被追踪。地面绘制按角色脚底偏移 38px，逻辑始终使用同一组区域坐标。圆形和交叉重叠也只命中一次；每次读招结束都有收招空档。

Boss 免疫普通硬直、抓取、击退和击倒。普通拳、重拳仍造成伤害并在超限时削减量表，但不会让它停止读招。进入 Break、超限转换或死亡时清除尚未结算的攻击和所有预警。

## 文件入口

- `src/boss-combat.js`：阶段、量表、招式顺序、预警几何和伤害规则。
- `src/boss-scene.js`：占位造型、血条、地面预警、AI、命中与练习入口。
- `src/main.js`：关卡第四区域、检查点、攻击与 Boss 规则衔接。

## 验证

本地 `npm test` 共 66 项通过，包含阶段边界、Break 伤害、固定预警、角落逃生空间、霸体与抓取限制、重叠判定只伤一次、死亡取消招式、重试和通关闭环。原有真实 Phaser Arcade Physics 检查继续验证所有攻击在 30／60／144fps 原地停步，受击后仍可正常击退。生产构建及 `git diff --check` 通过。

当前环境未安装浏览器；尝试下载 Chromium 返回 502／超时，尚未完成真实浏览器视觉与操作手感验收。程序绘制的 Boss 是占位素材，巴布最终战尚未加入。

建议手动试玩：先在挑战模式绕后躲横扫、离开落剑光圈；将生命打入超限，观察十字安全区；用 K 或 J-J-K 打出 Break，再输出；最后测试死亡 R 重试和击败后的完成画面。
