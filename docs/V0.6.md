# v0.6：受击与恢复

本轮沿着 v0.5 的角色动画接入进度，完成玩家受击、倒地、起身和可反复重玩的基础流程。第一段仍是原有的三个区域、六波敌人。

## 试玩

1. 向右进入第一处战斗区。敌人靠近后会显示红色普通攻击区域；移出范围可躲避，在出手前打中或抓住敌人可打断它。
2. 故意承受一次普通攻击，同时按住移动键：碧应先受击后退、短暂停顿，再恢复移动。硬直期间按 J/K/L/空格，不应提前取消硬直或恢复后补发动作。
3. 让同一敌人继续出手。每第三次出手有黄色“重击！”提示；命中后扣 2 点生命，碧侧倒、起身，恢复操作后仍短暂闪烁保护。普通攻击扣 1 点生命。
4. 抓着敌人时受到另一敌人攻击，应松开抓取；冲刺中受击应中断冲刺。
5. 倒地前攒满怒气，在可操作状态按空格，确认原本暴怒免伤仍有效。
6. 死亡后按 R，确认回到起点，生命重置，战斗区和怒气清空。重复死亡重开，双击方向键不应重复触发。
7. 完成六波后走到终点，按 R 可以重新游玩。清波途中被击败的敌人在淡出时不应继续攻击。

## 参数入口

| 参数 | 当前值 | 位置 |
| --- | --- | --- |
| 普通受击硬直 | 240ms | `src/player-state.js` → `PLAYER_REACTION.hurt` |
| 倒地停留 | 700ms | `PLAYER_REACTION.knockdown` |
| 起身时长 | 280ms | `PLAYER_REACTION.getup` |
| 恢复操作后的无敌保护 | 350ms | `PLAYER_REACTION.recoveryGrace` |
| 敌人普通/重击预警 | 340 / 560ms | `src/main.js` → `enemyAttack()` |
| 重击频率 | 每第三次开始出手 | `enemyAttack()` → `attackCount` |
| 普通/重击伤害 | 1 / 2 | `hurtPlayer()` |
| 普通/重击初始击退速度 | 220 / 340 | `hurtPlayer()` |

受击状态以游戏时间推进，长帧不会重新延长倒地或起身时间。角色只在恢复到可操作状态后接受新的动作。无敌保护期间允许移动和反击。

敌人预警开始后不会继续转向追踪玩家；预警框就是命中检测所用的矩形区域。敌人的出手次数在预警开始时计数，被打断也计一次。

## 当前美术边界

现有 `idle.png`、`walk.png`、`punch.png` 保持原样。受击使用停帧与红色闪烁，倒地和起身使用旋转作为占位表现；未新增或伪装成正式的受击精灵图。接下来可按 `docs/SPRITES.md` 补 `hurt`、`knockdown` 和 `getup`。

## 验证范围

`npm test` 覆盖状态切换、伤害免疫、受击中断、预警躲避/打断、死亡敌人退出战斗、延迟刷怪、场景重置和冲刺键监听清理；场景测试使用引擎替身。CI 另执行 `npm run build` 验证 Vite 与 Phaser 的实际打包。动画观感、物理位移和战斗难度仍需按以上步骤在浏览器中试玩。
