# 角色精灵图制作规格

> v0.8 已接入完整基础动作。现有两张新增原图采用不等距分区，运行时归一为 256×256、脚底 y=244；具体以 `src/player-art.js` 和 `public/characters/bii/README.md` 为准。下文是后续人工重绘时建议的交付规格。

本项目采用 2.5D 横版清场玩法。正式美术建议使用透明 PNG 精灵图或 Sprite Sheet。

## 一、肌肉碧：最小可玩版

第一阶段不用一次画几十张。先准备下面 8 组动作就足够替换当前蓝色占位角色。

| 动作 | 建议帧数 | 用途 |
| --- | ---: | --- |
| 待机 idle | 4 | 呼吸、耳朵/翅膀/身体轻微起伏 |
| 行走 walk | 6 | 上下左右移动统一使用，左右通过程序镜像 |
| 普通拳 punch | 4 | J 的前两段攻击，可先共用 |
| 三连击终结 combo_finisher | 5 | J-J-J 第三击 |
| 重拳 heavy | 5 | K 与 J-J-K 终结 |
| 冲刺 dash | 3 | 双击左右后的冲刺状态 |
| 冲撞 dash_attack | 5 | 冲刺中 K 的肌肉碧究极冲撞 |
| 抓取 grab | 3 | 抓住敌人时的持续姿势/痛殴姿势 |

最小版总计约 **35 帧**。

如果需要进一步压缩，也可以让普通拳、三连终结、重拳部分共用关键帧，把第一批控制在 **26～30 帧**。

## 二、肌肉碧：正式版追加动作

正式版推荐再补：

- 受击 hurt：2～3 帧
- 倒地 knockdown：3 帧
- 起身 getup：4 帧
- 投掷 throw：5 帧
- 抓取痛殴 grab_punch：4 帧
- 暴怒 rage：4～6 帧
- 暴怒待机 rage_idle：4 帧（也可以继续使用普通待机，只加特效）
- 胜利 victory：6～8 帧

完整主角建议最终控制在 **60～75 帧左右**，已经足够做出很丰富的动作感。

## 三、每帧尺寸

推荐统一使用：

- 单帧画布：`256×256 px`
- 透明背景 PNG
- 角色脚底位置固定
- 所有帧角色中心尽量一致
- 脚底基准建议放在 `y = 225` 左右
- 左右方向只画“面向右”，游戏内用 `flipX` 镜像

肌肉碧本体建议实际占画布高度约 `170～210 px`，四周留出拳头、尾巴、翅膀和夸张动作的空间。

不要为了每一帧省透明区域而裁成不同尺寸，否则游戏播放动画时角色会抖动。

## 四、Sprite Sheet 排列

推荐“一种动作一张横条图”，比把所有动作塞进一张超大图更容易维护。

例如：

```text
public/characters/bii/
  idle.png          # 4×1，1024×256
  walk.png          # 6×1，1536×256
  punch.png         # 4×1，1024×256
  combo_finisher.png# 5×1，1280×256
  heavy.png         # 5×1，1280×256
  dash.png          # 3×1，768×256
  dash_attack.png   # 5×1，1280×256
  grab.png          # 3×1，768×256
```

这样后面改某个动作不会影响整套角色图。

## 五、AI 直接生成是否可行

可以直接生成，但最好不要要求 AI 一次生成一张包含 60 帧的超级 Sprite Sheet。

更稳定的流程是：

1. 先确定一张“肌肉碧标准立绘 / 标准待机姿势”。
2. 以这张为固定角色参考。
3. 每次只生成一种动作，例如“4 帧普通拳横向 Sprite Sheet”。
4. 所有动作统一 `256×256` 单帧规格、透明背景、同一画风、同一身体比例。
5. 最后检查脚底锚点，并用程序或图像工具重新对齐、切格。

AI 生成最容易出现的问题不是画质，而是：

- 每帧肌肉大小变化
- 脸型变化
- 翅膀/角/尾巴数量变化
- 脚底位置漂移
- 帧与帧之间动作不连续

所以“标准角色参考图 + 每次只生成一个动作”会稳定很多。

## 六、敌人素材

普通杂兵可以更省：

- 待机：3 帧
- 行走：4 帧
- 攻击：4 帧
- 受击：2 帧
- 倒地：2 帧

每种杂兵约 **15 帧** 即可。

普通骑空士完成后，可以复用动作骨架，只换服装和武器做斯巴达、剑豪、古战场骑空士。

## 七、场景素材

格兰赛法甲板不需要做成一张 3600px 的巨大背景。正式版建议拆成：

- 天空：可平铺或宽背景
- 远景云层：2～3 张独立透明图，用不同速度滚动形成视差
- 木甲板：可横向平铺纹理
- 护栏：可横向平铺
- 主桅：独立 PNG
- 绳索：独立 PNG 或程序绘制
- 木箱 / 木桶：独立透明 PNG
- 船首、门、楼梯：大型独立 PNG

这样既节省文件大小，也方便修改战斗区域长度。
