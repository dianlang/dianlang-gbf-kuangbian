# GBF 狂扁小朋友

一个用于 2027 年愚人节彩蛋的浏览器横版清场动作游戏原型。

主角暂定为肌肉形态的碧。当前仍使用程序绘制的占位角色，优先把《狂扁小朋友》式的移动、连招、击退、倒地、抓取、投掷、暴怒和横版清场流程做完整。

## 本地运行

```bash
npm install
npm run dev
```

然后打开 Vite 提供的本地地址。

## 当前操作

- WASD / 方向键：八方向移动
- J：普通拳
- J → J → J：三连拳，第三击击倒
- J → J → K：重拳终结
- K：重拳，直接击倒
- ← ← / → →：向对应方向冲刺
- 冲刺中 J：冲刺拳
- 冲刺中 K：肌肉碧究极冲撞
- L：抓取面前的近距离敌人；再次按 L 可以松手
- 抓住敌人后 J：连续痛殴
- 抓住敌人后 K：把敌人投掷出去
- 空格：蜥蜴怒气槽满后进入暴怒状态
- R：死亡后重新开始
