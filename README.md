# GBF 狂扁小朋友

一个用于 2027 年愚人节彩蛋的浏览器横版清场动作游戏原型。

当前版本使用程序绘制的占位角色，不依赖正式美术素材，目标是先验证移动、攻击、击退、敌人追击与清波手感。

## 本地运行

```bash
npm install
npm run dev
```

然后打开 Vite 提供的本地地址。

## 当前操作

- WASD / 方向键：八方向移动
- J：普通拳
- K：重拳

## 当前已实现

- 2.5D 横版清场式上下移动
- 普通攻击 / 重攻击
- 攻击判定与受击闪白
- 击退与屏幕震动
- 简单追击 AI
- 敌人 HP
- 清波提示
- 根据 Y 坐标自动调整角色前后遮挡层级
