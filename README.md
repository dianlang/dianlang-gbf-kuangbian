# GBF 狂扁小朋友

一个用于 2027 年愚人节彩蛋的浏览器横版清场动作游戏原型。

主角暂定为肌肉形态的碧（ビィ）。当前仍使用程序绘制的占位角色，不依赖正式美术素材，优先把《狂扁小朋友》式的移动、连招、击退、倒地和暴怒手感做出来。

## 本地运行

```bash
npm install
npm run dev
```

然后打开 Vite 提供的本地地址。

## 当前操作

- WASD / 方向键：八方向移动
- J：普通拳
- J → J → J：三连拳，第三击击倒
- J → J → K：重终结技
- K：重拳，直接击倒
- ← ← / → →：向对应方向冲刺
- 冲刺中 J：DASH PUNCH
- 冲刺中 K：ULTIMATE BII TACKLE
- Space：`トカゲゲージ` 满后进入暴怒状态
- R：死亡后重新开始
