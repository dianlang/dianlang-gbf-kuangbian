# GBF 狂扁小朋友

一个用于 2027 年愚人节彩蛋的浏览器横版清场动作游戏原型。

主角为肌肉形态的碧，已接入完整基础动作与透明动作图集。当前版本为 **v0.9**：六波杂兵之后加入道中 Boss「神将希耶提」，形成完整的甲板试炼。敌人、Boss 与场景仍使用程序绘制的占位素材。

当前可运行版本在 `main` 分支（v0.6–v0.9 开发记录见 [PR #1](https://github.com/dianlang/dianlang-gbf-kuangbian/pull/1)）。使用 Codespaces 试玩时请选择 `main`。

## 本地运行

```bash
npm install
npm run dev
```

然后打开 Vite 提供的本地地址。建议使用 Node.js 22.12 或更新的 22.x 版本。

页面下方可选择「完整关卡」「神将希耶提挑战」「主角动作预览」。Boss 挑战也可直接在本地地址后加 `/?boss=siete`；无需先清六波杂兵。

Windows PowerShell 如果提示禁止运行 `npm.ps1`，可使用 `npm.cmd install` 和 `npm.cmd run dev`。

验证命令：

```bash
npm test
npm run build
```

GitHub Actions 会在推送和提交 PR 时运行以上检查。测试包含轻量引擎替身与真实 Phaser 物理逐帧检查，不代替浏览器中的动画和手感试玩。

## 当前操作

- WASD / 方向键：八方向移动
- J：普通拳
- J → J → J：三连拳，第三击击倒
- J → J → K：重拳终结
- K：重拳，直接击倒
- ← ← / → →：向对应方向冲刺
- 冲刺中 J：急停冲刺拳
- 冲刺中 K：急停肩撞
- L：抓取面前的近距离敌人；再次按 L 可以松手
- 抓住敌人后 J：连续痛殴
- 抓住敌人后 K：把敌人投掷出去
- 空格：蜥蜴怒气槽满后进入暴怒状态
- R：死亡或通关后重新开始；已进入 Boss 战时，满血重试 Boss

## v0.9：道中 Boss 神将希耶提

- 甲板扩展至 4560px，保留原有六波杂兵，之后进入独立锁屏 Boss 战；击败神将才完成第一段
- 三种范围攻击：定向横扫、三圈落剑、超限阶段的交叉剑阵。预警固定，不追踪玩家，攻击后有反击空档
- 生命降至 60% 进入超限 Overdrive；持续命中削减量表，重击更有效；清空后进入 4.2 秒 Break，期间不出招、承伤 ×1.5
- Boss 不可抓取、击退或击倒，普通命中不打断蓄力；进入 Break 会立即取消未落下的招式
- Boss 独立血条、阶段量表与中文读招提示；占位体型大于肌肉碧
- 初次进入 Boss 区域恢复生命；死亡后按 R 满血再战，页面下方可回完整关卡
- 保留 v0.8.1 的全部攻击停步规则，包括冲刺接招、抓取痛殴和投掷

参数、试玩步骤与当前验证范围见 [docs/V0.9.md](docs/V0.9.md)。

## v0.8.1 本轮更新：攻击强制停步

- 所有攻击从起手到收招都锁定横向、纵向移动与朝向，按住方向键也不会漂移攻击
- 冲刺接 J/K 当场刹停，保留招式、伤害和击退，取消角色自身的前冲位移
- 清除攻击首帧已计算的物理位移，避免高速冲刺接攻击时仍滑出一步
- J-J-J / J-J-K 的缓存连招先衔接再处理移动，连打过程中不会被反向按键转身
- 攻击期间的方向双击不触发冲刺，也不会留到收招后误触发；收招后按住方向即可继续走

规则、验证与试玩步骤见 [docs/V0.8.1.md](docs/V0.8.1.md)。

## v0.8 本轮更新

- 主角放大：站立约 116px，普通敌人 76px，形成约 1.5 倍的身高差；统一脚底落点，后续 Boss 预留更大体型
- 新增上勾重拳、冲刺、肩撞、伸手抓取、抓取痛殴、投掷、受击、倒地、起身、暴怒发动、胜利和战败姿势
- J-J-J、J-J-K、冲刺 J/K、抓取 J/K/L 均使用各自的动作时间线
- 伤害在出拳/冲撞有效帧结算；出手前受击会取消攻击，每次攻击对同一敌人最多结算一次
- 出招锁定朝向与移动；冲刺攻击在 v0.8.1 改为起手急停，全程无自身位移
- J 的前两段支持收招前 140ms 的 J/K 输入缓存，受击或暴怒会清空缓存
- `animations.html` 提供 22 组动作预览，支持慢放、暂停、重播和左右镜像

启动开发服务器后，在本地地址后加 `/animations.html` 即可查看动作预览；该页面也包含在生产构建中。

动作清单、参数与试玩步骤见 [docs/V0.8.md](docs/V0.8.md)。

## v0.7 更新

- 普通骑空士：6 点生命，移动较快，沿用普通拳与每第三次重击
- 斯巴达：10 点生命，移动较慢，使用金色头盔、蓝甲和盾牌占位造型
- 斯巴达的正面盾牌可挡住 J 三连拳和冲刺轻拳；K、J-J-K、冲刺 K 或暴怒攻击可破防
- 可绕背攻击、L 抓取，或投掷其他敌人撞倒持盾斯巴达
- 盾击有 740ms 固定范围预警，出手后留出 650ms 反击空档；转身有 450ms 延迟
- 原有六波中斯巴达数量依次为 0、1、1、2、2、2，逐步引入混合编队
- 敌人头顶显示名称、生命条和持盾／破防状态；首次遇见斯巴达时提示应对方法
- 修复敌人上下错位时停在原地、反复挥空的问题

规则、参数与试玩步骤见 [docs/V0.7.md](docs/V0.7.md)。

## v0.6 更新

- 普通受击造成 240ms 硬直，打断连招、冲刺与抓取，击退不再被移动输入覆盖
- 敌人每第三次出手使用重击：黄色范围和“重击！”提示，命中扣 2 点生命并击倒
- 倒地 700ms → 起身 280ms → 恢复操作；恢复后有 350ms 保护时间，闪烁表示无敌
- 普通攻击有 340ms 预警，重击有 560ms 预警；出手方向与攻击区域在预警开始时锁定
- 可上下走出预警范围，也可出拳或抓取打断蓄力；空格暴怒保留原本的免伤效果
- 硬直、倒地和起身期间不接受攻击、抓取、冲刺或暴怒，期间按下的动作键不会在恢复后突然执行
- 修复死亡后 R 重开时关卡、波次、怒气等状态残留的问题
- 修复死亡敌人淡出期间仍可攻击/重复受击，以及波次敌人尚未出完就提前结算的问题
- 修复长按方向键被当成双击冲刺，以及重开后键盘回调叠加的问题
- 通关后也可按 R 从头再玩

v0.6 的受击旋转占位表现已在 v0.8 替换为专用动作姿势。

受击系统的试玩要点和可调整参数见 [docs/V0.6.md](docs/V0.6.md)。
