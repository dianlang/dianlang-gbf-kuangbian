# 肌肉碧角色素材

## 当前文件

| 文件 | 内容 | 原图规格 |
| --- | --- | --- |
| idle.png | 待机，4 帧 | 1024×256 |
| walk.png | 行走，8 帧 | 2048×256 |
| punch.png | 普通拳，4 帧 | 1024×256 |
| combat-atlas.png | 重拳、冲刺/冲撞、抓取/痛殴、投掷，16 个姿势 | 1254×1254，RGBA |
| reactions-atlas.png | 受击、倒地、起身、暴怒/胜利，16 个姿势 | 1254×1254，RGBA |

三张原有文件保留原样。两张新增原图由内置 imagegen 参考现有 punch.png 制作；提示词见 `docs/ART-PROMPTS.md`。

游戏和动作预览页共用 `src/player-art.js`：按指定行列边界读取原图，统一打包为 256×256 的运行时帧，脚底 y=244。同一原图采用同一缩放，倒地和蹲下不会被重新放大。源文件不是等距网格，不能直接按四等分切开。

`src/player-actions.js` 定义动作顺序、每帧时长及命中时机。轻拳共用 punch；第三拳、重拳与重拳终结共用上勾拳关键姿势，依靠不同节奏区分；暴怒待机与胜利共用力量展示。左右方向使用程序镜像。

新增中间帧或替换姿势时，修改素材分区和动作表即可。正式制作规格见 `docs/SPRITES.md`，本轮接入详情见 `docs/V0.8.md`。
