# 肌肉碧角色素材

这里存放肌肉碧的正式游戏精灵图。

当前代码会自动读取：

- `idle.png`：4 帧待机动画，建议整图 `1024×256`
- `walk.png`：行走动画；目前支持 6 帧或 8 帧，8 帧建议整图 `2048×256`
- `punch.png`：4 帧普通拳动画，建议整图 `1024×256`

后续计划文件：

- `combo_finisher.png`：三连击终结动画
- `heavy.png`：重拳动画
- `dash.png`：冲刺动画
- `dash_attack.png`：冲刺攻击动画
- `grab.png`：抓取动画

所有 Sprite Sheet 统一规则：

- 单帧 `256×256 px`
- 透明背景 PNG
- 横向排列
- 角色脚底基准保持一致
- 默认只画面向右，游戏内向左时自动镜像

普通拳 `punch.png` 当前代码按 4 帧读取：蓄力 → 出拳 → 完全伸展/命中 → 收拳。
